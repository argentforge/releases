# Security Policy

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Booksmith or DarkQuill, please **do not open a public issue**.

Instead, send a detailed report to the ArgentForge team privately. Include:
- The affected application and version
- Steps to reproduce the issue
- Potential security impact

We will investigate immediately and coordinate a fix.

## Security Scope

Both Booksmith and DarkQuill operate 100% offline with zero cloud backends. The application security boundary is focused on local archive integrity and cryptographic encryption (.gyj vault security).
